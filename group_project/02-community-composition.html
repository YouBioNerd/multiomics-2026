Study B — do the three contraceptive methods differ in community composition?

The question: do the vaginal communities of people on the pill, the injectable, and the ring differ from each other?

The plan, built on Tuesday’s ordination module:

  1. Look — draw a PCoA map of the samples, coloured by arm. A PCoA (principal coordinate analysis) turns the pairwise distances between samples into a 2-D map: points that are close together have similar communities. We use Bray-Curtis distance, computed on relative abundances: 0 means two samples share the same species proportions, 1 means nothing in common.
  2. Test — PERMANOVA (Anderson 2001, https://doi.org/10.1111/j.1442-9993.2001.01070.pp.x). In plain words: it asks “how much of the difference between samples is explained by arm, and is that more than we’d see if we shuffled the arm labels at random?” The R² is the “how much” (like R² in a regression); the p-value comes from comparing it against 999 shuffles of the labels.
  3. Worry — check that the answer survives different distances, a stricter low-depth filter, and the fact that BV status (which dominates these communities) is tangled up with arm.

Study B has one sample per participant, so there are no repeat visits to worry about.

2½. A PERMANOVA caveat: different places, or just more spread out?

PERMANOVA can come out significant for a boring reason: one group being more scattered than the others, rather than sitting in a different place. betadisper (Anderson 2006, https://doi.org/10.1139/E06-036) tests exactly that — “do the groups differ in how spread out they are?” — and a large p-value here is good news: it means the PERMANOVA above is about where the groups sit, not how scattered they are. (The warning about “negative squared distances” that this chunk prints under the hood is expected — it comes from the PCoA step inside betadisper and does not affect the test.)

# dist_get() pulls the distance matrix back out of psb.
dist_b <- dist_get(psb)

set.seed(202)

Neither is close to significant (BV: p ≈ 0.5; arm: p ≈ 0.8): the groups are equally spread out. So the BV signal above — the thing that actually structures these communities — is a genuine shift, not a scatter artefact.

3. Which arms differ?

An overall test of three groups can miss a difference that exists between only two of them, so we test the three pairs separately. Caveat: three tests means three chances to be fooled by chance. The last column applies a Holm correction, which pays that back — treat anything that only survives the uncorrected column as suggestive, not settled.

pairs <- list(c("pill", "injectable"), c("pill", "ring"), c("injectable", "ring"))

pairwise <- map_dfr(pairs, function(pr) {
  # prune_samples() keeps only the listed samples. We find the IDs with an
  # ordinary dplyr filter first, because subset_samples() would need to see
  # `pr` from inside the sample table, where it can't look.
  ids <- d$metadata$sample_id[d$metadata$arm %in% pr]
  t <- as.data.frame(perm_get(
    prune_samples(ids, ps) |>
      tax_transform("compositional") |> dist_calc("bray") |>
      dist_permanova(variables = "arm", n_perms = 999, seed = 202, verbose = FALSE)
  ))
  tibble(comparison = paste(pr[1], "vs", pr[2]),
         r2 = round(t$R2[1], 3), p_value = t$`Pr(>F)`[1])
})

# p_holm: adjusted for having run three tests. Roughly, the smallest
# p-value gets multiplied by 3, the next by 2, the last is left alone.
pairwise |>
  mutate(p_holm = round(p.adjust(p_value, "holm"), 3))
# A tibble: 3 × 4

4. Worry: robustness

Four checks: the same distance on raw counts, two other distances, and the 15,000-read filter from section 0.

  • Raw-count Bray-Curtis is what we’d get if we forgot to convert to proportions: shallow samples then look different just for being shallow.
  • Aitchison (CLR transform + Euclidean distance) treats the data as compositional and works on log-ratios instead of raw proportions.
  • Jaccard ignores how abundant a species is — only whether it is there.
  • Dropping the nine low-depth samples asks whether shallow samples were adding noise that drowned the signal.
# A helper that runs the PERMANOVA for arm and returns just its R2 and p.
test_arm <- function(ps_obj) {
  t <- as.data.frame(perm_get(
    ps_obj |> dist_permanova(variables = "arm", n_perms = 999, seed = 202, verbose = FALSE)
  ))
  tibble(r2 = round(t$R2[1], 3), p_value = t$`Pr(>F)`[1])
}

low_depth <- lib$sample_id[lib$reads < 15000]

robust <- bind_rows(
  `Bray (proportions)`       = test_arm(psb),
  `Bray (raw counts)`        = test_arm(ps |> tax_transform("identity") |> dist_calc("bray")),
  `Aitchison (clr + euc)`    = test_arm(ps |> tax_transform("clr", rank = "species") |> dist_calc("euclidean")),
  `Jaccard`                   = test_arm(ps |> tax_transform("binary") |> dist_calc("jaccard")),
  `Bray (prop.), low-depth dropped` = test_arm(
    prune_samples(setdiff(d$metadata$sample_id, low_depth), ps) |>
      tax_transform("compositional") |> dist_calc("bray")),
  .id = "approach"
)
robust

5. A sanity check from the biology

If the pill’s communities really sit apart, a much simpler summary should show it too: the total share held by Lactobacillus species, the genus that dominates healthy vaginal communities.

tax <- d$taxonomy

d$metadata |>

Verdict

The three methods’ communities overlap far more than they differ. On the Bray-Curtis map, arm explains about 3% of the differences between samples (p ≈ 0.15) — not significant on its own, and it stays at ~3% (p ≈ 0.11) once BV, pH, STI status and sequencing batch have had their share. What clearly does structure these communities is BV status (R² ≈ 14%, p ≈ 0.001), and BV is distributed fairly evenly across the three arms, so it is a rival explanation of the pattern we went looking for rather than a confounder of a real arm effect. The dispersion check in section 2½ confirms that the BV signal is a genuine shift, not an artefact of one group being more scattered.

The pairwise tests point the same way as the sanity check: the pill group (median Lactobacillus share 85%, vs ~45% for the other two arms) separates from the injectable group (p ≈ 0.03, though ≈ 0.1 once the three comparisons are corrected for), while the ring sits between and differs from neither. Dropping the nine low-depth samples strengthened the overall arm signal (R² ≈ 6%, p ≈ 0.01) — the shallow samples were adding noise — which makes pill-vs-injectable more believable, but it is one comparison out of three and deserves the gene-table follow-up before we call it.

Bottom line for the group: the overall answer is “not much”, with one suggestive exception (pill vs injectable) worth chasing tomorrow with the gene table.

Choices made

  • Used Bray-Curtis on relative abundances (compositional transform) as the main distance; alternatives run as robustness checks: Bray-Curtis on raw counts, Aitchison (CLR + Euclidean) and Jaccard. (The original version of this report used raw counts as the main distance, which the text described as “relative abundances” — they are not the same thing, and raw counts make shallow samples look artificially different.)
  • Tested with PERMANOVA, 999 permutations, seed 202 for reproducibility; an alternative is 9999 permutations, which only steadies the third decimal.
  • Used by = "margin" in the multi-variable model so each variable’s R² does not depend on listing order; the alternative (by = "terms") was not used.
  • Included sequencing batch in the multi-variable model (it was negligible, R² ≈ 0.5%); the alternative was to leave it out.
  • Defined low depth as < 15,000 reads, read off the gap in the library size histogram, kept those samples in the main analysis and did a sensitivity analysis without them; the alternative is to drop them throughout, which moves the headline p-value from ~0.15 to ~0.01.
  • Reported pairwise tests with a Holm correction alongside the raw p-values; the alternative (raw p-values only, yesterday’s version) makes pill-vs-injectable look stronger than it is: 0.03 raw, ≈ 0.10 corrected.
  • Checked multivariate dispersion (betadisper) so the PERMANOVA results are not a spread artefact; the alternative was to trust PERMANOVA alone, which can be significant purely because one group is more scattered.
  • Asked the question of the species table only; the same pipeline runs on the gene table and is the next step.
